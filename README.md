# Poster-to-Grid
Tile a poster layout into a 2x2 or 3x3 grid. (PNG-Poster-to-PNG-Sheets). Useful for preparing images to be printed on smaller 24x18 inch or 17x11 inch sheets that can be taped together. The quality is much better than printing on 8.5x11 inch (letter) sheets and can be printed at various printing services locations such as FedEx or UPS.

This tool was created as a backup for immediate printing, in case a normal poster printing service wait time is too long.
